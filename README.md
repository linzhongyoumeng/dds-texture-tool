# DDS Texture Tool

通用 DDS 纹理批量处理工具 - Electron 桌面版

## 功能特性

- **批量处理**：批量缩放 DDS 纹理尺寸，支持 BC1/BC3/BC5/BC7 等格式转换
- **智能过滤**：仅处理大于目标尺寸的文件，等于上限的文件自动跳过
- **扫描预览**：扫描前预览文件列表，可选择性处理部分文件
- **自动备份**：处理前自动备份需要处理的文件，支持一键回滚
- **单文件回滚**：支持按文件夹分组查看备份详情，选择性回滚
- **文件信息**：批量查看 DDS 文件尺寸、格式、大小等信息，支持导出 CSV
- **白天/黑夜主题**：支持切换主题，自动保存设置
- **中英文界面**：支持中文/英文切换
- **内置 texconv**：开箱即用，无需额外配置

## 快速开始

1. 下载最新 Release 中的 ZIP 包
2. 解压后运行 `DDS Texture Tool.exe`
3. 选择输入目录（包含 DDS 文件的 Mods 目录）
4. 设置目标尺寸（默认 3072x3072）
5. 点击"扫描预览"查看哪些文件会被处理
6. 确认无误后点击"开始处理"

## 核心规则

- **只处理大于目标尺寸的文件**：等于上限的文件不会被处理
- **只备份需要处理的文件**：避免浪费磁盘空间
- **预览模式**：勾选后只模拟处理，不修改任何文件

## 技术栈

- Electron 31.x
- Node.js 20.x
- DirectXTex (texconv.exe)
