⚠️ 重要说明

输出格式二选一：

  • -f <格式> 用于 DDS 输出格式（如 BC7_UNORM）
  • -ft <类型> 用于图片输出格式（如 PNG/JPEG）
  • 不能同时使用 -f 和 -ft！

📐 基础参数

-w <n> 目标宽度（像素）
-h <n> 目标高度（像素）
-f <fmt> DXGI输出格式（DDS专用）
-ft <type> 输出文件类型：PNG/JPEG/TGA/BMP/TIFF

🗺️ Mipmap

-m 0 生成完整Mipmap链（推荐）
-m 1 不生成Mipmap

⚡ 压缩质量（仅DDS）

-bc d 快速压缩
-bc q 高质量压缩

🔍 缩放滤镜

-if LINEAR 线性（默认）
-if CUBIC 三次（推荐）
-if FANT Fant（放大时最好）
-if POINT 最近邻（像素风）

🎨 颜色/Alpha

-srgb 启用sRGB颜色空间
-pmalpha 预乘Alpha

🔄 变换

-hflip 水平翻转
-vflip 垂直翻转

⚙️ 性能

-nogpu 禁用GPU，使用CPU模式
--single-proc 单线程压缩

📋 DDS格式列表

BC1_UNORM DXT1，不透明
BC3_UNORM DXT5，带Alpha
BC5_UNORM 双通道，法线贴图
BC7_UNORM 高质量，推荐通用
R8G8B8A8_UNORM RGBA8888，未压缩

使用帮助

1. 快速开始

  • 内置 texconv，开箱即用
  • 选择输入目录或单个 DDS 文件
  • 用快速预设一键设置目标尺寸
  • 点击"扫描预览"查看文件列表
  • 点击"开始处理"执行批量转换

2. 备份与回滚

  • 处理前默认自动备份
  • 备份回滚页面支持文件夹视图
  • 支持单文件回滚和对比
  • 支持手动备份、清理旧备份

3. 命令模式（专业模式）

  • 自行构造 texconv 命令参数
  • 提供20+预设模板一键填充
  • 实时命令预览，复制命令
  • 命令大全参考，含常用参数说明
  • 支持DDS转PNG/JPG/TGA等图片格式

4. 主题与语言

  • 右上角切换白天/黑夜主题
  • 语言下拉切换中文/英文
  • 设置自动保存
